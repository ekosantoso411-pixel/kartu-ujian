Aplikasi Cetak Kartu Ujian

Petunjuk Penggunaan:

  1. Buat file Excel / Spreadsheet berisi data siswa.
  2. Pastikan baris pertama adalah judul kolom: No_Peserta, Nama, Kelas, NISN, Ruang, Kode.
  3. Simpan file tersebut dalam format CSV (Comma Delimited).
  4. Klik tombol di bawah untuk mengunggah file CSV tersebut.
  5. Klik "Cetak Kartu" untuk memunculkan dialog print.
Belum ada data. Silakan unggah file CSV atau gunakan data contoh.
